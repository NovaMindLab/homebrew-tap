# NovaMindLab Homebrew Tap

Official Homebrew Tap for [ShareCLIP](https://novamindlab.github.io/AIShare-Grabber/) — Private P2P AirDrop Alternative, Local AI Photo Search & Media Suite.

## Quick Install

```bash
# One-liner install
brew install --cask novamindlab/tap/shareclip
```

Or add the tap first:

```bash
brew tap novamindlab/tap
brew install --cask shareclip
```

## Upgrade

```bash
brew upgrade --cask shareclip
```
